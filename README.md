Side project for a networking class that doesn't make us program...

Building a locally networked messaging platform based on a small amount of code from the textbook.

I chose to use a circular linked list for the data structure of most of the mechanics of this project as I already had an implementation to use which I am expanding on as I need for this program.

I will be implementing a database to store user info that the server will use to route messages between clients, those messages will land in my implementation of a queue which may be tailored from its
original state if needed to serve the purposes of this program.
